Kenapa ANUx-WRT

Dibangun untuk kecepatan,
ditala untuk stabilitas

Tema SPA Modern

Footstrap — antarmuka single-page 2x lebih cepat dengan diagram topologi jaringan visual. Vantage — command palette, flyout sidebar, dan live status sinyal per klien.

Modem 4G/5G Terpadu

luci-app-5gmodem: sinyal real-time, carrier aggregation multi-band, lock band LTE/5G, SMS & USSD, terminal AT command, fix TTL otomatis, dan peta BTS.

File Manager Golang

FileBrowser — single binary hemat RAM (~15-25 MB), web code editor, upload/download/extract, streaming media. Bebas bloatware PHP.

Kernel & Sistem Ditala

Google BBR congestion control, ZRAM ZSTD anti-OOM, hardware monitor presisi, uhttpd & rpcd tuning, dan auto-repair filesystem ext4 read-only.

Siap Multi-Tunnel

OpenClash (Mihomo), Nikki + Zashboard, PassWall, FusionTunX, Clashoo, hingga Tailscale — instalasi terintegrasi dalam satu image.

Build Otomatis

GitHub Actions ImageBuilder: pilih cabang OpenWrt/ImmortalWrt, target perangkat, tunnel, dan ukuran rootfs — firmware jadi tanpa compile manual.

Mulai Cepat

Flash dalam 4 langkah

01

Unduh image

Pilih firmware sesuai perangkat & kernel di katalog atas, lalu unduh file .img.gz.

02

Tulis ke media

Flash dengan Balena Etcher / Rufus ke MicroSD, eMMC, atau USB drive. Untuk Amlogic gunakan varian MODSDCARD.

03

Boot & sambung

Colok media, nyalakan perangkat, hubungkan ke 192.168.1.1 — login root / root.

04

Konfigurasi

Atur WAN, Wi-Fi (ANUx / ANUx2026), modem 4G/5G, dan tunnel favoritmu lewat LuCI.
