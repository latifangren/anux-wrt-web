/// MULAI CEPAT

Flash dalam 4 langkah

01

Unduh image

Pilih firmware sesuai perangkat & kernel di katalog atas, unduh file .img.gz.

02

Tulis ke media

Flash dengan Balena Etcher / Rufus ke MicroSD, eMMC, atau USB. Amlogic → varian MODSDCARD.

03

Boot & sambung

Colok media, nyalakan perangkat, buka 192.168.1.1 — login root / root.

04

Konfigurasi

Atur WAN, Wi-Fi (ANUx / ANUx2026), modem 4G/5G, dan tunnel favoritmu.
