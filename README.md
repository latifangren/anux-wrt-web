# ANUx-WRT Official Web Portal

Web portal resmi, landing page, dan pusat unduhan firmware untuk proyek **[ANUx-WRT](https://github.com/latifangren/ANUx-WRT)**.

---

## 🌐 Tentang Proyek

Repositori ini direncanakan sebagai situs web statis (didukung oleh **GitHub Pages** atau platform hosting statis modern lainnya) yang menyajikan:

* **Pusat Unduhan Firmware**: Katalog rilis firmware per-kategori perangkat (x86_64, Raspberry Pi, TV Box Amlogic, Rockchip, dan Allwinner).
* **Integrasi GitHub Releases API**: Mengambil daftar rilis firmware terbaru dan aset `.img.gz` secara dinamis dari repositori [latifangren/ANUx-WRT](https://github.com/latifangren/ANUx-WRT/releases).
* **Panduan Pengguna & Flashing**: Tutorial langkah demi langkah untuk flashing firmware ke MicroSD / eMMC / USB drive dan konfigurasi awal modem 4G/5G serta tunnel.
* **Changelog & Catatan Rilis**: Ringkasan fitur baru, pembaruan kernel, dan perbaikan bug pada setiap rilis firmware.
* **Antarmuka Responsif & Modern**: Desain clean dengan dukungan Dark Mode dan Light Mode otomatis.
